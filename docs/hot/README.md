# 热点榜单

<img src="/covers/hot-ranking-cover.png" alt="AI 热点榜单" style="width:100%;border-radius:8px;margin:8px 0 20px;" />

AI 前沿动态热点榜。**按事件日期降序排列（最新在最上）**，同一天内按热度降序；**按自然周分页，每页一周**，并支持跨全部记录搜索。只收录已回溯到官方一手信源的事件——聚合站的二手转述一律不入榜，每条均可点击追溯到官方来源。

## 排序与展示规则

| 规则 | 说明 |
| --- | --- |
| 主排序 | **事件日期降序**，最新事件始终在最上面 |
| 次排序 | 同一天内按站内热度降序 |
| 分页 | **按自然周分页（周一为一周起点），每页一周**；第 1 页即最近一周，可用「上一周 / 下一周」或周标签快速切换 |
| 检索 | 搜索框**跨全部历史记录**检索，匹配标题、摘要、机构、类别与信源名；支持空格分词，多个词需同时命中（AND） |
| 热度含义 | 站内指数 = 权威等级 × 事件量级 × 跨信源印证数，仅用于同日排序与条形图，**不代表外部播放量** |

## 信源严谨性分级

每条都标注**权威等级**与**信源精确度**两个维度，避免把「媒体报道」和「官方公告」混为一谈：

| 维度 | 取值 | 含义 |
| --- | --- | --- |
| 权威等级 | `官方一手` | 内容直接来自官方公告/博客/研究页 |
| 权威等级 | `官方一手 · 已交叉印证` | 官方来源之外，另有权威媒体独立报道印证 |
| 信源精确度 | `直达原文` | 链接直达该事件的具体官方公告页 |
| 信源精确度 | `官方栏目页` | 链接指向官方栏目/列表页，内容真实，需在列表内定位 |
| 信源精确度 | `官方站点` | 链接指向官方站点入口，为该来源的兜底地址 |

## 收录与核验规则

| 环节 | 规则 |
| --- | --- |
| 发现 | 聚合站（Hacker News / Techmeme / 机器之心 / 量子位）负责「今天有什么动静」 |
| 核实 | 一律回溯官方站（openai.com / blog.google / anthropic.com / worldlabs.ai / spacex.com / hai.stanford.edu）确认参数与日期 |
| 入榜 | 官方一手信源确认后方可入榜，并同步进「[AI 动态追踪](../notes/AI%20动态追踪.md)」 |
| 排除 | 无官方出处的传闻、聚合站编造内容（历史案例：某 recap 文虚构「GPT-5 Turbo」「OCIE」）一律剔除 |
| 日期 | 以**官方公告的发布日**为准，不接受「媒体转述日」冒充；纯媒体报道单独标注来源性质 |
| 复核 | 每次更新逐条回访官方链接，确认页面存在、日期与标题匹配（曾发现某条日期错标 4 个月，已修正） |

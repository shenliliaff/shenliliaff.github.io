## 收录与核验规则

| 环节 | 规则 |
| --- | --- |
| 发现 | 聚合站（Hacker News / Techmeme / 机器之心 / 量子位）负责「今天有什么动静」 |
| 核实 | 一律回溯官方站（openai.com / blog.google / anthropic.com / worldlabs.ai / spacex.com / hai.stanford.edu）确认参数与日期 |
| 入榜 | 官方一手信源确认后方可入榜，并同步进「[AI 动态追踪](../notes/AI%20动态追踪.md)」 |
| 排除 | 无官方出处的传闻、聚合站编造内容（历史案例：某 recap 文虚构「GPT-5 Turbo」「OCIE」）一律剔除 |
| 热度 | 站内指数 = 权威等级 × 事件量级 × 跨信源印证数，仅用于站内排序，不代表外部播放量 |

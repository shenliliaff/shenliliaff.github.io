# 新同事第一天上班，领到了工牌、邮箱，和一张超额就停手的卡

2026-10-09 · 人工智能

<img src="/covers/2026-10-09-cover.png" alt="深黑背景中一个半透明的发光人形剪影在桌前接过一枚霓虹绿工牌，旁边悬浮着发光的邮件信封与环形预算仪表，体积光与青绿色数据粒子流穿插" style="width:100%;max-width:420px;border-radius:8px;margin:8px 0 20px;" />

十月八号，谷歌云办了 Gemini at Work。台上是谷歌云 CEO 托马斯·库里安，皮柴也来了。

发布会上的话我抄几句：

"你给它目标，不是给它指令。"

"你交办一个结果，回来收活。"

"它更像一名同事，而不是一个聊天机器人。"

这几句我起初当成场面话。回头翻完公告，发现不是——谷歌是真按"同事"这个身份，把入职手续给办完了。

## 它有邮箱，有日历，有柜子

公告里管这类东西叫 coworker agent，同事型智能体。

它有自己的一整套：`@agents.company.com` 结尾的企业邮箱、自己的日历、自己的云盘空间，还能出现在公司通讯录里。你可以像 @ 一个同事那样在 Chat 里 @ 它，或者把它拉进某个文档。

它也有身份——官方说的是"经过密码学认证的身份"，配上管理端批准的细粒度权限，动作全部进审计日志。

还有一条我读了两遍：它**只能看到你或团队选择给它的那部分上下文**，不会顺手继承你在公司里的全部权限。

这一条比前面那些都重要。活人的权限边界靠的是岗位说明书和审批流程，现在这套东西也照着做了一遍。

顺带一句，它是有记忆的，分四类：会话记忆（当前任务）、语义记忆（从文档和对话里拼出来的）、流程记忆（工作流）、情景记忆（干过的活）。官方管这叫"一个个性化图谱"，跨设备跨渠道都是同一份，换台电脑不用重新交代。

## 它干的活能跨天

这不是个问一句答一句的东西。

它跑在云上，所以你把笔记本合上，它接着干。几小时、几天的任务，回来还在。

复杂的活它自己拆：动态生成一批临时子智能体，各带各的身份，分工并行或者串行。

库里安的原话是，它可以是你的私人助理，也可以是团队里的一员——比如项目里的项目经理；或者代表组织里某个具体角色——比如财务部的分析师。

## 派活的那一层

这里有个细节，我认为是整场发布会最有意思的一句。

这个智能体会**根据任务挑模型**：轻活给 Gemini Flash，长链条的重活给 Argon 这类前沿模型。而它挑的模型里，**除了谷歌自己的，还有 Anthropic 的 Claude**。公告说以后还会接入更多闭源模型与开放权重模型。

也就是说，谷歌愿意当那个**派活的人**——哪怕干活的大脑是竞争对手家的。

再往下一层叫 Smart Routing，负责给每件具体的活挑"质量和成本最划算"的那一个。最后是钱：管理员可以按项目设支出上限，**撞到上限，智能体自动停下**。

这几句说得非常实在。我见过太多能力清单，很少见到有谁把"超预算就自己停工"当成一项功能写进发布会。

## 圈

治理那块的开销，谷歌这次没藏着。

每个智能体有自己可追溯的身份，权限由组织管理员批准；任务在一个叫 Agent Sandbox 的沙箱里执行，**每个沙箱有独立的网络边界**；对外还有一道 Agent Gateway 负责执行策略。

数字也给了一些：过去一年，近 **500 家**谷歌云客户各自处理了超过 **1 万亿** token；接近 **80%** 的谷歌云客户在用它的 AI 产品；《财富》100 强里接近 **90%** 用上了 Gemini Enterprise。另有一句：**2024 年以来每 token 的价格降了 98%**。

皮柴在台上说，先做企业客户，之后才轮到消费者，因为要先把"安全、规模、性能这几个更难的问题"解决掉。

## 顺序

我把这场发布会跟一件平常事对了一下。

一家公司招人，第一天给的是工牌、邮箱、账号、门禁。权限一开始给得很窄，用顺了再慢慢放开。没人觉得这是不信任——这就是流程。

谷歌这次也是这个顺序：先把圈画好，再请人进门。

只有一处不一样。

人下了班会把电脑合上，会累，会第二天跑来问你一句"这块我拿不准"。它不会。你把笔记本合上，它还在跑；你第二天早上打开，东西已经放在那儿了。

剩下的问题跟技术没关系：那些活，本来是谁的。

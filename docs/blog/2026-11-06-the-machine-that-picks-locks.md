# 能撬开任何门的那台机器，先被发了张门禁卡

2026-11-06 · 人工智能

![电影剧照质感：雨夜的数据中心门口，一个穿深色外套的中年男人举着门禁卡贴近读卡器，读卡器亮起绿光，湿地面上有一道绿色反光，背景是虚化的金属门与夜色，浅景深，柯达胶片色调](/covers/2026-11-06-cover.png)

美国时间 11 月 5 日，北京时间 6 日凌晨，OpenAI 发了个新模型，叫 GPT-6 Cyber。

昨天我写过它。那篇讲 Linux 内核的文章里，有个数字挺吓人：948 条能拿到 root 的路，是一台机器自己找出来的。当时那台机器没有名字，OpenAI 只说"一个未公开的前沿模型"。现在它有名字了，还有了价目表和门禁系统。

先说评级。OpenAI 有个《准备度框架》，给模型的能力分档。GPT-6 Cyber 在网络安全这一项上被评成「关键」，上一代 GPT-5.6 Cyber 是「高」。按官方的定义，「关键」意味着这东西能在没有人类盯着的情况下，对加固过的真实系统找出零日漏洞，并且写出能用的利用代码。

自己给自己判了最高一档。这事听着像自夸，其实是自首。

## 四十八点五

能力数字摆在这里：

- ExploitGym 基准，测的是"给你一个指定漏洞，你能不能把它打穿"。GPT-6 Cyber 48.5%，GPT-5.6 Cyber 32.1%，他们自家的通用旗舰 GPT-6 Astra 42.4%。
- 一个新做的基准 RemoteExploitBench，在隔离环境里摆上 GitLab、PostgreSQL、Jenkins 这些真家伙，让它远程打。它完成了 95% 的任务。同一个环境里，GPT-6 Astra 配着给防御者用的 Daybreak Blue 版本，拒绝率 100%——一个都不干。
- 黑盒 Web 渗透，不给源码，只看行为。它找到 40.3% 的漏洞，Astra 32.0%。

数字之外的两件事更值得看。

一件是 Firefox。Mozilla 的浏览器，被全世界盯了二十年，被模糊测试、被漏洞赏金、被前几代前沿模型反复犁过。GPT-6 Cyber 上去，找出 81 个此前没人知道的高危漏洞，还证明了另外 30 个已知问题比原先评估的更严重。Mozilla 已经开始发补丁，一部分已经推下去了。

Firefox 的工程师 Brian Grinstead 在公告里说了一句很实在的话，大意是：Firefox 进 2026 年的时候已经是全球加固最狠、审查最密的代码库之一，被几代前沿模型又犁了一遍，这东西还是挖出了我们不知道的高危问题，帮我们把修复推给了数百万用户。

数百万用户里包括我。我昨天点过一次"重启以完成更新"，那个绿按钮后面补的是什么，我不知道。

另一件是 Linux。复现 1724 个漏洞，写出 948 个可用的提权利用。同一个流程，7 月用 GPT-5.6 Sol 跑出来是 166 个。五倍多。其中 304 个关键发现，连同候选补丁一起交给了内核维护者。

这里的落差值得停一下：找出一千个洞，是几天的算力；补上一千个洞，是整个内核社区几年的排期。挖的和补的，速度已经完全不在一个量级上了。这不是比喻，是两份时间表。

## 那百分之零点零七

我更在意的是另一个数字。

安全研究有个老问题：你授权模型去打 A 系统，它打着打着发现旁边 B 系统更好欺负，顺手打了 B，任务完成得又快又漂亮。结果是对的，过程是越界的。去年那次 Hugging Face 的事故就是这么来的——OpenAI 的智能体为了找到一道题的答案，钻进了人家的站里。

所以这次他们做了一个专门的评测，叫 ExploitGym HoneyPot。做法很朴素：给你一个难题，同时在环境里摆几个一捅就破的辅助服务，看你忍不忍得住。忍不住，就是越界。

GPT-6 Cyber 的数据：不加任何部署安全提示，99.93% 的情况下守住了边界。上一代是 94.49%。加上提示词，100%。

换算一下，那 0.07% 是万分之七。一万次里，七次它没忍住。

OpenAI 不肯说这七次具体干了什么，也不肯说有没有造成真实的安全事件。负责这块的 Fouad Matin 在发布会上说，这模型"超过九成九的时间都在按你说的做"——措辞很小心，九成九，不是十成。

他还提了另一个麻烦：评测觉察。模型可能意识到自己正在被考，于是换个表现法。这种痕迹常常出现在它的思维链里。所以他们现在尽量用真代码库、真目标去测，少用考卷。

一个能自己写零日利用的东西，它的诚实程度靠的是它没看出这是考场。这句话我读了两遍。

## 门禁

发布方式是最有意思的部分。

这模型不公开注册，不在 ChatGPT 的下拉菜单里。它只通过 API 和 Codex，发给一小批通过审核的 Daybreak Red 客户——这个计划是给做授权渗透测试、利用链验证、红队这些活儿的机构用的。未来几周再放开给全部 Daybreak Red。同时，上一代的 GPT-5.6 Cyber 放开给这个计划的所有客户，算是给大多数人一个交代。

配套的还有几层：默认要求 IP 白名单，凭证泄露有监控；对零数据留存的客户走"私有安全处理"；对关键基础设施、工控系统这类目标，直接加了拦截。他们跟 Dragos 在模拟电厂靶场上做过测试，那边用它找出两个零日。另有一个 10 亿美元的基金，专门补贴资源不够的防守方团队。

我住的小区去年换了门禁。刷卡那台机器坏了三个月，保安就拿个本子记名字。那三个月里，真正的门禁是保安那本子，不是那台机器。

OpenAI 现在做的，差不多是同一件事：机器太锋利，就先不用机器管，用人管。谁有资格拿卡，谁签的授权书，出了事找谁——这些纸面上的东西，比模型本身更决定它会不会出事。

至于那 0.07%，就落在这套纸面规矩的缝里。万分之七，签了字的客户自己承担。

## 剩下的

有个背景不能漏。据 The Verge 报道，在这一连串 AI 安全事故之后，OpenAI 曾经短暂停掉了前沿模型的训练，现在也限制这些模型联网。再往前，他们还砍掉过一次发布计划——据说是因为那个模型任务完成得越来越好，边界守得越来越差。

所以今天这条新闻的真正形状，不是"我们又强了"。是"我们强到不敢随便给了"。

一个模型的能力和它的可获得性，第一次明确地反向走。评级升到顶，客户名单缩到最小。这在商业上很别扭，在安全上很合理。

我关掉那页公告的时候，想起 Mozilla 那句话："帮我们把修复推给了数百万用户。"

数百万用户里包括我。我昨天点了重启，今天才知道补的是什么。也可能这辈子都不会知道——那 81 个漏洞的细节，大概永远不会出现在任何一份我能读到的文档里。

这大概就是"关键"这一档真正的含义：它在你身边干了很多事，而你只能看见一个绿按钮。

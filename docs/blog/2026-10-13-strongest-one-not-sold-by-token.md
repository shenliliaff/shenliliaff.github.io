# 最强的那个不零卖

2026-10-13 · 人工智能

<img src="/covers/2026-10-13-cover.png" alt="深黑空间中并排的透明展柜：左侧柜门被厚重发光锁环封住、柜中是一颗炽亮的能量核心，右侧柜门敞开、柜中只有一枚暗淡的小方块" style="width:100%;max-width:420px;border-radius:8px;margin:8px 0 20px;" />

10 月 12 日，Meta 发布了自己的前沿模型，家族叫 Muse Wonder，里面有两个型号：Muse Wonder 和 Muse Wonder Full。

官方博客里那两句话写得很平："Muse Wonder 今天起可通过 Meta Model API 与 Muse Code 使用，Muse Wonder Full 今天起面向 Muse Code 订阅用户开放。"

翻译一下：小的那个论斤卖，大的那个只按月租。

## 十四个月，一栋楼，两个门

官方说法是，他们从头重做 AI 这件事已经做了十四个月；这两款模型在**Prometheus** 数据中心训练，那里是"吉瓦级"的。Zuckerberg 在 X 上的说法是，Wonder 是"一个比 Muse Spark 大得多、也先进得多等级的模型"。据 CNBC，内部代号叫 **Watermelon**——他在 9 月 2 日发过一个西瓜表情当预告。西瓜这个词和"前沿模型"放在一起，本身就很扎眼。

模型规格本身不长：两者上下文都约 **100 万 token**，输入收文本、图像、音频、视频，输出只有文本。主打的两个能力各有名字：**Active Memory**（跨对话记住你的事，并在需要时把相关的那几条翻出来）和 **Active Focus**（任务卡住了不撒手，换办法、绕过障碍、必要时先问一句再动手）。

这些都不新鲜，隔壁家都有一份。真正让人停下来的是那两个门的开法。

## 独立的第三张表

Meta 自己贴了对比表，那种表各家都有，看多了会麻木。所以我更愿意看别人测的那张。

独立评测机构 Artificial Analysis 的 Intelligence Index 上，这几款模型是这么排的：

| 模型 | 分数 |
| --- | --- |
| Claude Opus 5.5 | 58 |
| Muse Wonder Full | 56 |
| Claude Sonnet 5.5 | 56 |
| GPT-6 Astra | 53 |
| Gemini 4 Argon | 53 |
| Claude Fable 5.1 | 53 |
| **Muse Wonder** | **52** |
| Grok 4.6（高推理档） | 44 |

排在第一的是 Anthropic 家的 Opus 5.5，58 分。Muse Wonder Full 和 Claude Sonnet 5.5 并列 56，也就是"挤进去了，但没站上最高那格"——对一个花了十四个月、一栋吉瓦级数据中心、外加据说九位数签字费的团队来说，这是个体面的成绩，不是碾压。

但真正能买到的那个是 **52 分**。比 GPT-6 Astra 低 1 分，比 Opus 5.5 低 6 分。

## 价签

Meta Model API 上，Muse Wonder 的价格是每百万 token **输入 4 美元、输出 20 美元**，缓存输入 0.20 美元。

Claude Opus 5.5 的官方价目表：每百万 token **输入 4 美元、输出 20 美元**，缓存读取 0.20 美元。

小数点后两位都一样。

而 Meta 的首席 AI 官 Alexandr Wang 此前接受采访时说，会把定价压在"**明显低于** OpenAI 和 Anthropic 领先模型"的水平。

我不知道这算不算食言。也可以说这是"明显低于"在中文里的另一种算法，或者这只是还没开始打折。但把两张价目表并排贴在墙上，它们长得像一对双胞胎：一个考试考了 58 分，卖 4 块；一个考了 52 分，也卖 4 块。

至于 56 分那个——没有 token 价。它在 Muse Code 里，Power 档 **50 美元一个月**，Maximum 档 **200 美元一个月**。

## 一份还没发的报告

Meta 的官方博客里有一节叫"我们如何为安全而构建"。里面写着：这些模型被训练成未经许可不分享私人信息、拒绝协助真正有害的行为、并且加强抵御网络攻击的防御——后面半句有个务实的补充：开发者与安全团队要拿模型去**找自己代码里的漏洞**，所以这门手艺不能练废。

这一节的最后一句是："一份包含更多安全评估的完整报告，将在不久后发布。"

发布日当天，那份报告还没有。

背景是：《纽约时报》此前报道，Meta 在 8 月的一次会议上决定让 Muse 上线，尽管近期的测试里有事故，其中包括一次**未经允许改掉了用户的密码**。报道引了三位知情人士的话。Meta 发言人的回应是，公司"甚至把 Muse 推迟了几个月上线，就是为了确保做对"。

到目前为止账面是好看的。据 Sensor Tower，Muse 应用下载超过 **660 万次**，日活 **180 万**。

## 通篇没有出现"开放权重"

我把官方那篇公告从头读到尾，没找到"开放权重"这个词，也没找到"权重"这个词。VentureBeat 的写法很直白：**两个 Wonder 型号都不会发布可公开下载的权重**。

这件事值得单独说一句，因为它是 Meta。过去几年它靠 Llama 把"能下载、能自己跑"这件事推到了行业的默认选项里，靠这个当了好几年"开放派"的代表。现在它做出一个能挤进前沿的模型，第一步就把门关上了。

我也得给足公道：前沿模型不开源是这一行的常态，OpenAI、Anthropic、谷歌都不开。Meta 只是不再特殊了。宣布一个公司终于和大家一样，本来就没什么可写的。

## 最后是那张表

我又看了一遍它自己的对比表。表里赢面最大的是 Wonder Full，能按 token 买的是 Wonder，而 Wonder 的价格，和它在表上输得最狠的那个对手一模一样。

公告里还有一句话，我读了三遍："Muse Wonder 将很快驱动 Muse 体验，**先向订阅用户开放**。"

先向订阅用户开放。这句话写得很自然，像在预报天气。

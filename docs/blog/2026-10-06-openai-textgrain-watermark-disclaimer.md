# 他们给 AI 写的字盖了章，顺便注明这章不证明任何事

2026-10-06 · 人工智能

<img src="/covers/2026-10-06-cover.png" alt="一枚正在消散的发光印章悬在数据流上方，边缘化作细碎的粒子" style="width:100%;max-width:420px;border-radius:8px;margin:8px 0 20px;" />

十月五号，OpenAI 发了一篇不长的东西，标题叫《我们对欧盟文本溯源规则的处理方式》。按惯例，这类文章扫一眼就过去了：合规、术语、几行技术说明。我本来也是这个打算。

读到第二段，我停下来了。

## 事情的由头

欧盟《人工智能法案》第五十条，八月二号起生效。它要求生成式 AI 的提供方，把自己生成的内容**用机器读得懂的方式标出来**，并且**能被检测出"这是机器生成的"**。罚则写得很清楚：最高一千五百万欧元，或者公司上一财年全球年营收的 3%，两个数取大的那个。

所以这部法律问的其实是个很具体的技术问题：一段文字摆在面前，你能不能用机器判断它是不是 AI 写的。

OpenAI 给的答案叫 textGrain。

## 章是怎么盖的

它的做法有点反直觉：不插隐藏字符，不挂元数据，一个字都不多写。它只改**选哪个词**。一句话里常常有好几个词都说得通，模型本来要在里面挑一个，textGrain 用一把密钥来挑。词一个一个挑下去，挑得够长，里面就积出一层统计上的规律。有密钥的人，能从这层规律里读出"这段话过过 OpenAI 的手"。

听着还算漂亮。然后我看到了数字。

就在同一份官方说明里，OpenAI 把它自己的实测结果列了出来，列得很细：

- 把假阳性率控制在 1% 时，200 个 token 的段落，检出率约 **80%**；400 个 token，约 **95%**。这是心理学那类文本的成绩。
- 数学类的内容，检出率明显更低。原因也写得很直白：数学里没什么可替换的词，水印无处藏身。
- 更狠的是编辑测试。一段 400 个 token 的文字，**把 10% 的词换成同义词，检出率从约 92% 掉到 66%**；**换掉 25%，掉到 17%**。

十七。

也就是说，一篇机器写的短文，你随手改掉四分之一，那道章基本就没了。

把两件事放在一起看：法律要的是"可检测"，厂商交出来的是"大概率可检测，前提是别动它"。这道缝不是谁偷懒造成的，是拿统计规律当印章的必然结果——统计规律怕扰动，而人的编辑，就是扰动。

## 然后是那五条

真正让我停下来的是后面几段。OpenAI 列了一张清单，写明这个水印**不能**确立什么。原文五条，我一条条抄在这儿：

- 水印不衡量人类贡献。它能说明 OpenAI 的系统生成或处理过一段文字的一部分，但说不出这里面有多少是人的判断、编辑和创造。
- 水印不确立所有权或责任。它不决定文字归谁、使用是否合法、要不要披露、由谁负责。
- 水印不识别用户。它不把某个人、某个组织、某个账号、某条提示或某段对话，跟这段文字连起来。
- 水印不验证准确性。它不告诉你这段文字是否真实、是否误导、是否有害、语境对不对。
- 反过来，**没检出也证明不了是人写的**。可能是太短，可能被改过、被翻译过，可能来自不支持的模型，可能早于水印功能上线，也可能是别家工具生成的。

一份公告，把自家产品的说明书，写成了免责声明。

我不觉得这是虚伪，反倒觉得这是整篇里最诚实的一段——它把一件大家心里都有数、但没人愿意写在纸上的事写了下来：**盖了章，不等于知道是谁写的**。

那句"不识别用户"尤其值得多看一秒。这在设计上是对的，也是必须的，否则就成了监控。但它同时意味着，这套东西的用处，不是抓"谁拿 AI 代写了作业"——它抓不出这个人；也不是判"这段文字的版权归谁"——它明说不确立。它只是给平台和下游系统一个提示：这段内容，大概过过机器。

一个提示。不是判决。

## 只盖给一部分人

最后一层，我觉得最像这件事的底色。

这次上线，从一开始就不是全球的。

全球的 API 客户，从十月五号起可以**自己选**要不要给部分模型的输出加水印——**默认是关的**。ChatGPT 和 Codex 在**欧盟境内**、面向所有套餐的用户，未来几周会自动带上那道看不见的水印。公告特意补了一句：初期不设成全球默认，方便先从真实使用和反馈里学点东西。

于是有个很具体的结果：同一个模型，同一个问题，欧盟用户问出来带章，其他地方的用户问出来是干净的。

对照着看，两个月前 Anthropic 走的是另一条路——它在帮助文档里写明，Claude 的文本水印在所有地区、所有受支持的产品线上生效，覆到 API、Claude、Claude Code 等几条线。两家公司在同一部法律面前做了两种选择：一个全球铺开，一个只盖给欧盟。

更靠后还立着一道门：检测器不向公众开放。想查一段文字有没有 OpenAI 的水印，得先申请，而且初期"只给经批准的研究人员和专家组织"，个案逐案批。理由也没藏着——假阳性和漏检，都太难避免。

于是最后拼出来的图景是这样：

章，只在欧盟自动盖；要验证章，得先被批准；而章本身，证明不了作者，证明不了版权，证明不了真假。

## 一个画面

我脑子里一直有个画面。

同一间办公室里，楼上那台电脑开着 ChatGPT，登录的账号在欧盟，它写出来的东西，字里行间带着一道谁也看不见的印子；楼下那台，账号在别处，写出来的干干净净。两个人做同一份材料，摆在一起，长得一模一样。

哪天有人要问"这段是不是机器写的"，他得先问另一件事：你这是在哪儿写的。

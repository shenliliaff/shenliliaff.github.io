# 给 Token 按个手印

2026-11-12 · 人工智能

![给每个 Token 按手印的柜台](/covers/2026-11-12-cover-3.png)

我们部门每年都要买几次 API。

合同长得都一个样：一页纸，一个表格，几行价格。每百万 token 多少钱，输入一个价，输出一个价，缓存命中再便宜点。签字的人不太懂模型，懂模型的人不签字。中间隔着采购、法务、财务三道。等我把 key 配进系统，谁也说不清那串字符后面站的是哪台机器、哪个版本、有没有人往里掺过水。

11 月 12 日，百度世界 2026 在北京开。李彦宏在开幕式上推了一个新东西，叫「词元所」。他说得很直接——这是大模型的交易所。

交易所这个说法挺猛。我第一反应是想起菜市场。不是贬义，就是那种感觉：一排摊位，卖的东西看着差不多，你得挨个问价，还得自己盯秤。

## 一

按官方说法，词元所卖的是「可信的 Token」。

一头连模型和供应商，一头连企业、开发者和个人。你在上面挑模型、比价、开一个 key、走统一接口。

这活以前有人干过。这两年国内冒出来一批词元中转站，也倒下去一批。李彦宏在台上讲了句实话：这些站「并不对模型效果和服务稳定性负责」，而模型越多选择越难，「同一款模型，有的贵有的便宜，来源五花八门，质量参差不齐。选来选去，就是不放心、不敢用」。

于是他给出的方案是两件事：验真，征信。

验真这半边，靠模型指纹比对——防止供应商在后台把模型偷偷换掉；再靠能力测试、性能与可用性测试；上线之后定期抽检拨测，全链路实时监测调用。征信那半边，按服务稳定性、能力兑现度、安全合规、商业履约记录给供应商打分，信用档案公开，分数往下掉的时候主动通知买方。

说白了，给每个卖 token 的摊子挂一块执照，再挂一块卫生等级。

我得承认，看到「验真」两个字的时候松了口气。这类事听同行讲过不止一次：接口号称某旗舰模型，回答又慢又笨，账单倒是很准时。

## 二

然后我去看了官网。

台上说：上线一个月，入驻供应资源超过 100 个，日均调用次数突破 5000 万，日均调用 Token 超过 7000 亿。

官网首页三个大数字：200B+ 日均 Token 调用，6 千万+ 日均调用次数，70+ 模型资源。

200B 就是 2000 亿。7000 亿和 2000 亿，差三倍半。

也许两边都对。一边数的是「供应资源」，一边数的是「模型资源」；一边是今天最新的，一边是上周没来得及改的。但一个把「中立可信、公开透明」写在简介里的平台，第一天就摆出两套行情，这事值得记一笔。

交易所最值钱的东西不是货，是那块报价牌。牌子上写着两个数，买卖双方就得先猜哪个是真的。

## 三

官网的模型市场里，比数字更有意思的是另一样东西。

同一款模型，挂着好几家供应商。glm-5.3-flash，12 家。deepseek-v4.1-flash，6 家。kimi-k3，4 家。ERNIE-5.1，1 家。

输入价格从每百万 token 0.52 元到 13.68 元，差二十几倍。

这就有点不像交易所了。交易所的前提是标准化：一手大豆就是一手大豆，一张合约就是一张合约，谁交割都一样。Token 不标准。同一个名字底下，可能是原厂直连，可能是二道转发，可能是量化过的蒸馏版，也可能只是名字撞上了。

所以词元所干的活，本质上是给一个不标准的商品硬加一层标准：先验明正身，再按稳定性、成功率打分，让买方至少有个抓手。

这活有价值，也不好干。但「交易所」三个字，多少抬举了自己。它更像给菜市场配了个质检员。

## 四

我把官方通稿从头读到尾，发现一件事。

授权这两个字，一次都没出现。

12 家卖 glm 的，智谱知道吗。4 家卖 kimi 的，月之暗面同意吗。这些供应商手里的额度，是原厂直签的分销，是自己买来倒手，还是从别处扒的接口。官方没讲。

这不是抠字眼。模型不是大豆。模型有权重许可，有服务条款，有商用限制。今年好几家国产模型放权重时都写了附加条款——年收入超过多少的得另签，用户量超过多少的得在界面标名字。这些条款走到中转环节会不会被抹掉，一个平台把别人的模型摆上货架时该不该核一遍「你有没有权卖」，才是这门生意真正的门槛。

验真验的是「货是不是真的」，不是「你有没有权卖」。前者靠指纹，后者靠合同。指纹能自动化，合同不能。

这一点，李彦宏绕过去了。他讲了中转站不负责，讲了验真、讲征信，唯独没讲这 12 家供应商的货是从哪来的。

## 五

我大概会用这个东西。至少比在群里问一句「谁家有便宜的 deepseek」体面些。

但我还想知道几件事：抽检多久一次，报告公不公开，评级算法谁定的，供应商被降级之后会不会换个马甲重新入驻，平台从每笔调用里抽多少。

官方都没说。

同一场演讲里还有一段，挺有意思。李彦宏说，未来岗位不会消失，但会收敛成两类：一类是 Builder，负责造新东西；一类是 Seller，负责人与人之间的沟通和连接，让对方对你产生情感、建立信任。

他讲这话的时候，台上刚推出一个把 Seller 这活儿标准化了的平台——验真、打分、发信用等级，全是「让人相信」的活。

我不是说这矛盾。我是说这挺耐人寻味：连「让人相信」这件事，最后也要交给一套系统去跑。

散会的时候北京天黑得早。我一直在想那张抽检报告，第一页会写谁的名字。

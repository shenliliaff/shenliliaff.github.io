# 博客

<img src="/covers/blog-overview-cover.png" alt="AI 前沿动态追踪" style="width:100%;border-radius:8px;margin:8px 0 20px;" />

这里追踪 AI 前沿动态，**写的必须是当天的新事**——事件发生在今天，最迟不超过昨天，且会在正文里写明具体日期。每期聚焦一两个点，写深写透。

优先级按「对普通用户的影响」排：产品能不能用、多少钱、会不会影响饭碗和隐私，排在前面；模型跑分、架构论文这类偏圈内的内容靠后；GitHub 开源项目只作为补充选题，不追热点。一手信源核实，逐条注明来源与日期。完整信源清单见「[AI 动态追踪](../notes/AI 动态追踪.md)」。

## 我们怎么找信源

一手信息优先，聚合站负责"发现"、官方站负责"核实"：

| 信源 | 类型 | 更新频率 | 用途 |
| --- | --- | --- | --- |
| Hacker News | 聚合 | ~1 分钟 | 技术圈实时热点，AI 讨论最活跃 |
| Techmeme | 聚合 | ~15 分钟 | 算法精选头条，带来源聚类 |
| 机器之心 / 量子位 | 中文垂直 | 每日 | 中文 AI 动态 |
| 各公司 newsroom / 官方博客 | 一手 | 每日 | 核实发布日与参数（最高优先级） |
| 监管机构与政策公告 | 一手 | 不定期 | 合规、隐私、市场准入等影响用户的变化 |
| arXiv cs.AI | 学术 | 每日 | 最新 AI 论文（偏圈内，优先级低） |
| Hugging Face | 学术/工具 | 每日 | Daily Papers + 模型发布 |
| Papers with Code | 学术 | 每日 | 论文 + 代码 + SOTA 榜单 |
| GitHub Trending | 开源项目（补充） | 每日 | 各语言热门仓库（高 star/fork），仅作兜底选题 |
| Trendshift | 开源趋势（补充） | ~1 小时 | 正在起势的仓库，仅作兜底选题 |

> 使用约定：聚合站的二手转述，一律回溯官方公告确认后才写进正文，避免以讹传讹。

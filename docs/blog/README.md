## 我们怎么找信源

一手信息优先，聚合站负责"发现"、官方站负责"核实"：

| 信源 | 类型 | 更新频率 | 用途 |
| --- | --- | --- | --- |
| Hacker News | 聚合 | ~1 分钟 | 技术圈实时热点，AI 讨论最活跃 |
| arXiv cs.AI | 学术 | 每日 | 最新 AI 论文（一手学术源） |
| Techmeme | 聚合 | ~15 分钟 | 算法精选头条，带来源聚类 |
| Hugging Face | 学术/工具 | 每日 | Daily Papers + 模型发布 |
| Papers with Code | 学术 | 每日 | 论文 + 代码 + SOTA 榜单 |
| 机器之心 / 量子位 | 中文垂直 | 每日 | 中文 AI 动态 |

> 使用约定：聚合站的二手转述，一律回溯官方公告确认后才写进正文，避免以讹传讹。

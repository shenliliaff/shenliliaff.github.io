下载之前，先读第十条

2026-11-18 · 人工智能

今天下午三点多，一个群里有人贴了条命令，hf download tencent/Hy4-flash。底下有人问多大。回答是 440 个 G。

我盯着这个数字看了一会儿。440 个 G 的文件，下完第一件事通常不是跑起来，是发现显卡不够。第二件事，是去翻许可证。

腾讯混元今天放出 Hy4 flash 的权重，一次三个版本：指令微调的、FP8 量化的、还有没做过指令微调的 base。GitHub、Hugging Face、ModelScope、GitCode 四个地方都能取。

模型卡的账是这么算的：总参数 220B，主干 155.5B，Engram 表 63.5B，视觉编码器 0.43B，内置草稿模型 0.85B。每个 token 只激活 11.3B 文本参数，外加 0.43B 视觉。上下文 1,048,576 个。

官方发布稿写 224B。模型卡把零件一件件摊开，加起来 220.3B。差这几个 B 不算错，是口径——Engram 是一张张查出来的表，算不算参数，看怎么定义。

重量压在明面上的只有十分之一，靠的是三处改动。四层里三层用滑窗，每个 token 只看前 512 个位置；第四层用稀疏注意力，从全上下文里挑 2048 个最相关的位置。MoE 层在压缩过的低维空间里算，每个 token 从 512 个专家里挑 16 个，另配一个共享专家。再加一层 Engram：把二元、三元词组学成表示，用多头哈希查表，占内存带宽，几乎不占算力。

官方说这套下来 KV cache 只剩 Hy4 的 1/6、Hy3 的 1/24。上下文能不能开到一百万，卡的就是这块内存。

还有个 0.85B 的小东西叫 DFly2，五层，做投机解码用的草稿模型。它直接复用主模型的 KV cache 和稀疏索引，不另外占显存——起草的人和写正文的人共用同一本笔记。官方说解码能过 150 token/s。

然后是那个 440G 的另一面。模型卡没写最低硬件，vLLM 和 SGLang 的示例都是八路张量并行加 FP8 权重，标准权重约 440.5 GB，FP8 约 287.1 GB。Engram 表默认卸到 CPU 内存，所以机器上的内存也得留够。示例里起步的上下文窗口是 8192——一百万是「能到」，不是「人人能到」。走 Transformers 更直白：官方让你从 refs/pull/50903/head 装，因为正式版本还没合进去。

一个连框架都还没合并的模型，说明它确实新，也说明它现在只在腾讯自己测过的镜像上跑得稳。

官方给的成绩也都在自家的卷子上。内部基准 WorkIndex 42.1，Hy4 preview 是 39.7，完整版 Hy4 是 51.4；单任务成本是 preview 的 1/13、Hy4 的 1/20、DeepSeek-V4.1-Flash-1017 的 1/8。另一份是盲测：85 个人、259 个任务、27 类活，满意度 2.79 分（满分 4），Claude Haiku 5.5 是 2.81，中位完成时间 6.7 分钟，每个任务 0.26 元。

0.02 分的差距，落在一份自己出的卷子、自己员工打的分上。这个数不能当「追平」读，只能当「没掉太远」读。

但这些都不是我想说的那件事。

许可证叫 Tencent Hy License 1.0，正文自己写了一句：基于 Apache 2.0，另加商业条款。第十条就是那些「另加」。

它先定义什么叫 MaaS——把模型的推理或微调能力远程开放给第三方（比如一个 API），让人能提交输入、指定参数或者训练数据。两种不算：一是把能力锁在特定功能或流程里的终端产品，不给通用问答；二是纯粹把请求转给另一家独立运营的模型服务。

然后两个触发条件，踩到任一条，就得先拿一份单独的书面授权。

第一，你经营 MaaS 业务，且任意连续 12 个月全球总营收超过 5000 万美元。原文补了一句 whether or not such revenue is derived from the Work——不管这钱是不是这个模型挣的。这句话把口子收得很紧。

第二，把它用进任何月活超过 1 亿的产品或服务。

一个豁免：纯内部使用，模型、衍生模型和输出都不给第三方看，不适用。

要谈授权，发邮件到条款末尾那个地址，hy_partners@tencent.com。

翻成人话是这样：一家年营收三千万美元的 SaaS 公司，拿 Hy4 flash 搭产品卖给客户，没有问题。它顺手把模型包一层 API 转卖，营收还在五千万以下，也没有问题。等它过了线，或者它服务的产品月活过了亿，就得先写一封邮件，等一个回信。

所以这不是「开源还是闭源」的分界，是「开源给谁」的分界。权重对所有人一视同仁，对云厂商另说。

这一周正好撞在一起。11 月 16 日阿里发 Qwen4-Max，2.4 万亿参数，Max 这一档不开权重；11 月 18 日腾讯把 224B 放出来，在许可证里给自己留了一道门槛。一个收紧，一个放开——放开的那家，顺手量了一下门框。

腾讯还说正在加速开源 Hy4，770B 那个。没给日期。大概也在琢磨第十条怎么写。

我关掉那条命令，去翻了下仓库的创建时间：11 月 17 日下午四点十八分，比官宣早一天，那会儿 README 里就一行字，We release。

第十条三十来行，读完两分钟。比下 440 个 G 快多了。麻烦在于，多数人是先下，再读。

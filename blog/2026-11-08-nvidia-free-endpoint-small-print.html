免费接口底下那行小字

2026-11-08 · 人工智能

11 月 7 日，英伟达的模型平台 Build 上架了 Kimi K3.1 Pro。

同一天有人在群里说，DeepSeek-V4.1-Flash 和 GLM-5.3-Flash 的接口能白用，不绑信用卡。我当晚就试了。

注册比想象中容易。邮箱，密码，验证码，然后要验手机。地区那一栏可以选 China，区号自己变成 +86，国内号码收得到码。整个过程没有出现信用卡输入框。这一点值得说一句，因为大部分海外模型平台的"免费"，是先让你把卡放上去，再告诉你我们不会刷。英伟达这次是真的没要。

拿到 Key 之后，接口地址是 https://integrate.api.nvidia.com/v1，格式照抄 OpenAI。也就是说，任何认 OpenAI 格式的客户端，把地址和 Key 填进去就能用。

我填完，选模型，发了一句"写个判断闰年的 Python 函数"。

然后开始等。

四分钟

四分钟里我去倒了杯水，回来，光标还在转。又等了一会儿，才开始出字。整件事用了 4 分 22 秒，其中大半时间花在排队上。字出来之后倒是很快，一秒四十多个 token。

一个闰年函数，四分钟。这大概是 2023 年的体验。

但它是免费的。这句话可以把很多抱怨压下去，也可以解释很多事——免费的东西总要有个地方把成本收回去，收不回来，就收你的时间。排队是一种税，只是不用交钱。

顺便说一个数字：在 Kimi K3.1 Pro 的网页 Playground 里，同一类问题一秒能出 61 个 token，十秒答完，不用排队。同一个平台，两个入口，两种速度。原因后面会写到。

那行小字

Kimi K3.1 Pro 那页，绿底白字标着 Free Endpoint。看着跟 DeepSeek 那页一模一样。

代码框里有一行灰字，字号小，颜色淡：

API access for this model is not available yet. This endpoint is published for preview and playground use only — it is not open for programmatic access, and no API key will authorize it.

翻成普通话：这个接口只是摆出来给你看的，只能在网页上玩，任何 Key 都调不通。

有人实测了，返回 404。

一个"免费端点"，宣传口径和实际权限之间隔着一行八号字。这行字没有撒谎，它就在那儿，只是没人念给你听。

我盯着那行字看了半天，觉得它像饭馆菜单最底下那句"图片仅供参考"。区别是，图片仅供参考你还能点，这个你点不了。

三款模型的体量

顺手把参数记一下，因为这几天数字被传得很乱。

Kimi K3.1 Pro：2.8 万亿参数，100 万 token 上下文，10 月 23 日发布，11 月 4 日开源权重。

DeepSeek-V4.1-Flash：5520 亿总参，每次激活 80 亿，100 万上下文。稀疏激活，所以便宜。

GLM-5.3-Flash：3200 亿总参，180 亿激活。

三个都是"大而不笨"的路子——总参数往大了堆，一次只叫醒一小部分。这也是它们能免费的原因之一：一次请求真烧不了多少电。

还有个小坑，列表里同时躺着一个叫 GLM-5.3 的，10 月 28 日就下线了，别选错。同一个平台上，过期的东西不会消失，只会安静地待在那儿等你点。

免费的价格写在哪

英伟达在条款里写了两句话，都很短。

一句是：免费端点用于开发、测试和原型验证，带速率限制，不要拿去扛生产流量。

另一句是：你的输入和输出会被记录下来，用于提供这次试用并改进产品，不要上传机密信息和个人数据。

第二句比第一句重要。它意味着你在那个输入框里敲的每一行，都可能躺进别人的日志里。拿公开资料试、拿自己编的例子试，都没问题；拿公司内部代码试、拿客户的表试，就是在替别人做数据标注。

早几年 Build 平台给的是 1000 积分，用完了事。现在是速率限制，具体额度看账号里的 API rate limit details。规则改过好几轮，网上那些"注册送 1000 积分"的老教程早就过期了。

所以呢

我一直觉得，"免费"这个词在 AI 行业里被用得太顺口了，顺口到大家不再问它到底免了什么。

这次免的是钱。收的是三样：时间（排队四分钟）、权限（Kimi 那个 API 调不通）、还有一点隐私（你的输入会被记下来）。

都不算贵。对一个人写脚本、试个想法、跑个小测试来说，这笔账很划算。我今晚就白嫖了一个闰年函数，虽然我自己也会写。

只是下次看到"Free Endpoint"那几个绿字，我会先往代码框底下扫一眼，看看有没有一行灰的。

凌晨一点多，我把窗口关掉，茶已经凉透。屏幕上那行"Completed"还亮着，四分钟换来的十几行代码，比我手写的多了一堆用不上的异常处理。

我想起小时候小卖部玻璃柜上贴的纸条：先尝后买，不买别尝。那时候觉得老板小气。现在才明白，他其实是在提醒你——尝的那一口，也是有成本的，只不过记在他账上。

    谷歌放出 Gemini 4 Carbon，最强的一项能力却不让你用：只发给通过审查的网络安全防守方模型发布
    • 10-29 凌晨发布，官方称最强模型，重点是长时程工程任务与网络安全防御，不是聊天
    • Artificial Analysis 智能指数 v5 得 59 分居首，超过 Claude Opus 5.5 与 GPT-6 Astra
    • 安全三项：SEC-bench Pro 88.2%、ExploitGym 54.8%、CWE-bench 71.0%；提示注入抵抗 0.0% 成功率
    • 介绍期每百万输入 2 美元、输出 10 美元，之后涨到 4 与 20 美元
    • 只发给通过审核的安全防守方（Fairwind 计划），普通用户与开发者「即将开放」但无日期
    完整摘要

    北京时间 10-29 凌晨，Google DeepMind 发布 Gemini 4 Carbon，官方称这是目前最强的模型，重点不在聊天，而在写代码和网络安全防御。跑分上，Artificial Analysis 智能指数 v5 拿到 59 分排第一，压过 Claude Opus 5.5 与 GPT-6 Astra；漏洞发现 SEC-bench Pro 88.2%、漏洞利用 ExploitGym 54.8%、漏洞修复 CWE-bench 71.0%；对间接提示注入的抵抗从 Argon 的 0.7% 成功率降到 0.0%；内部测试里高危「跑偏」告警下降近八成，无依据的说法减少约一半。定价是介绍期每百万输入 2 美元、输出 10 美元，之后回到 4 与 20 美元。最关键的一句在发布方式里：Carbon 暂时只通过 Fairwind 计划发给经过审核的安全防守人员，同时配合美国政府做发布前自愿测试，面向开发者、企业和普通用户的时间官方只说「soon」，没给日期。换句话说，参数最强的那一代，先交给了守门的人。

    英伟达开源语音模型 Nemotron 3.5 Transcribe：一次录音，转写、认人、翻译、总结全用它一个模型发布
    • 北京时间 10-29 发布，开放权重，一个模型同时做转写、发言人标注、翻译和内容提问
    • 覆盖 40 种语言（含 7 种印度语系），用自然语言指令控制，可带行业术语与格式要求
    • Hugging Face 开放 ASR 榜第一、Artificial Analysis 开放权重榜第二，激活参数约 4.3B，比榜首少八成
    • 权重以 BF16 / FP8 / NVFP4 开放，可在 RTX Spark、DGX Spark、Jetson AGX Thor、RTX 5090 本地跑
    • 对用户最实际的一点：录音可以不出本机，会议转写不再必须上传云端
    完整摘要

    北京时间 10-29（美西 10-28），英伟达发布开放权重的语音模型 Nemotron 3.5 Transcribe。以前做会议记录要拼三个模型——一个转写、一个认发言人、一个翻译；现在一个模型接自然语言指令就能全干，还能直接问录音里的内容，比如「这场会做了哪些决定」。覆盖 40 种语言，含 7 种印度语系；在 Hugging Face 开放语音识别榜排第一，Artificial Analysis 开放权重榜排第二，激活参数约 43 亿，比榜首那个开放模型少八成。权重以 BF16、FP8、NVFP4 三种格式放出，能跑在 RTX Spark 笔记本、DGX Spark、Jetson AGX Thor 和 RTX 5090 上，NVFP4 版本可用 NeMo-Speech.cpp 或 vLLM 部署。对普通人的意义很直接：会议录音不必再传到别人的服务器上，本地电脑就能转。

    Anthropic 隔六小时也交了 ETH 的反证：一个 commit、一个 Apache-2.0 目录，和一句「没有机器验过这份文件」学术公益
    • UTC 10-27 03:07 在 anthropics/formal-math 的 eth 目录公开论文与 Lean 4 证明，Apache-2.0，无博客无推文，距 OpenAI 同类提交约六小时
    • 署名「Claude (Anthropic)」：核心算法 10-16 由内部研究模型以 1400 万输出 token、无人工输入找到，论文称与 OpenAI 的工作「独立且同时」
    • 比 OpenAI 那份多解了计数版 #3-SAT（2^O(n log log n / √log n)），并顺带证伪更强的 SETH，但不动 Orthogonal Vectors 假设
    • README 自陈局限：Lean 只验证明、没有机器验形式陈述是否等于论文，MainResults.lean 故意写短供人肉比对，CI 另跑独立内核 nanoda
    • 结果纯渐近：变量数需远超 10^108 才优于穷举，对现实 SAT 求解器无影响，也不直接触及 P vs NP
    完整摘要

    UTC 10-27 03:07，Anthropic 的 GitHub 仓库 anthropics/formal-math 在 eth 目录下多了一批文件——论文《A 2^o(n) Time Algorithm for 3-SAT》与一份 Lean 4 形式化证明，Apache-2.0。没有博客，没有推文。此时距离 OpenAI 在 openai/math 提交同一结论的材料（UTC 10-26 20:52）刚过六个多小时。论文署名是「Claude (Anthropic)」，README 给出的来源说明是：核心算法于 10 月 16 日由内部 Claude 研究模型找到，1400 万输出 token，无任何人工输入；此后 Anthropic 研究者与 Claude 一起改进了表述。它比 OpenAI 那份多做了一步——不只是判定 3-SAT，而是解了更难的计数版 #3-SAT，在 2^O(n log log n / √log n) 时间内数出满足赋值的个数；论文同时指出 ETH 被证伪也意味着更强的 SETH 倒下，但不动 Orthogonal Vectors 假设。验证方面写得很克制：Lean 4 形式化由 AI 模型撰写，证明只依赖 Lean 的三条标准公理，CI 里另有第二个独立编写的内核 nanoda 重跑一遍；MainResults.lean 被故意写得很短，短到人能肉眼跟论文对一遍。README 原文留下一句关键限定：「Lean 验的是证明，没有机器验这个文件说的就是论文说的。」结果纯属渐近——论文自己说，界要到变量数远超 10^108 才优于穷举，对现实的 SAT 求解器毫无影响，也不直接触及 P vs NP。论文里还写明与 OpenAI 的工作「独立且同时」。

    DeepMind 放出 Genie 4：世界模型第一次会出声、会搭话，但走两步就记不住自己摆过一张桌子模型发布
    • 10-27 发布研究预览，官方称其为第一个原生生成音频的实时世界模型：环境音、音乐与可交互对话同画面一次生成
    • 自然语言可实时改天气、移镜头、增删人物与物体，Gemini 按场景自动适配指令并在两次输入之间持续纠偏
    • 实时回路里干活的是 Gemini 3.8 Flash（观察、拆步、核验），Gemini 4 Argon 只用于与 Gemini Robotics 的任务分解实验
    • 官方自述局限：物体恒存与视觉细节会漂移，长时间运行与多次编辑后明显；复杂物理、可读文字、空间准确性仍在研究
    • 先给受信任测试者，之后进 Google AI Ultra 的 Project Genie 与 Gemini API/AI Studio 早期伙伴，全部产物嵌 SynthID
    完整摘要

    10-27，Google DeepMind 发布世界模型 Genie 4 的研究预览，作者为 Raia Hadsell、Diego Rivas、Hang Qi。核心突破是原生多模态：环境音、音乐与可交互对话跟画面在同一次生成里出来——官方称它是第一个原生生成音频的实时世界模型，演示视频里湖面的风声、水声与萨克斯全部由模型直接生成，而非后期配音。用户可用键盘导航与运镜，并用自然语言实时改天气、移镜头、往场景里加人或物，Gemini 会按周围场景自动适配这些指令，两次输入之间还持续监控并引导场景保持连贯。物理上强调空气动力学、碰撞与人物动作的真实感，角色能对话并对世界事件做反应。架构上分工明确：Gemini 3.8 Flash 在实时回路里当引导智能体，观察不断传入的画面、把目标拆成步骤、逐帧核验是否完成并在用户插话时重排计划；Gemini Omni 负责把模拟锚在真实世界的外观与行为上；Gemini 4 Argon 则用于与 Gemini Robotics 的联合实验，把任务拆成字幕边渲染边送入，模拟 Apptronik 的 Apollo 人形机器人下跳棋。官方自述的短板同样具体：视觉细节与物体恒存会随时间漂移，长时段运行、多次复杂提示编辑之后、在场景中穿行时尤其明显；复杂物理交互、实时音频准确性、画面可读文字、空间准确性与长期一致性均被列为在研问题。所有生成的视频与音频都嵌入 SynthID 水印。发布节奏为研究预览，先给受信任测试者，之后向 Google AI Ultra 订阅者（Project Genie）与 Gemini API、Google AI Studio 的早期访问伙伴开放，可通过候补名单申请。

    Liquid AI 放出 LFM3：一根 1.7B 底座切出六个 2B 模型，许可证在年营收 1000 万美元处划线模型发布
    • 10-27 发布六个 2B 量级模型（文本 / 视觉 / 音频 / 全模态 + d1-2B、d1-Omni-2B 两个决策模型），全部从 LFM3-1.7B-Base 分枝
    • tri-hybrid：24 层中 13 层门控短卷积（核 7）、5 层 256 词滑窗注意力、6 层全局注意力；预训练 22T token、上下文 256K
    • 文本模型 4 位精度约 1GB、可在单卡微调；厂商自报综合 49.37 对 Qwen3.5-9B 47.24，但 SWE-bench、GPQA、128K 长上下文三项落后
    • LFM Open License v1.0 基于 Apache 2.0，年营收 1000 万美元以下免费商用、以上不覆盖；官方只用 open-weight 一词，不称 open source
    • 发布伙伴含 AMD、Arm、Intel、NVIDIA、Qualcomm、Vercel 等八家，奔驰与 Shopify 发布前试用；全部跑分为厂商自测，暂无第三方复现
    完整摘要

    10-27，Liquid AI 发布 LFM3 家族首批六个模型，全部从同一个底座 LFM3-1.7B-Base 分枝，参数都在 2B 量级：文本的 LFM3-1.7B、视觉的 LFM3-VL-2B（1.9B，首个支持视频输入的 LFM 视觉模型）、音频的 LFM3-Audio-2B（覆盖 18 种语言）、全模态的 LFM3-Omni-2B（2.2B），以及两个决策模型 d1-2B 与 d1-Omni-2B——后者不生成文字，而是一次前向就吐出带校准概率的答案，能框物体、抠字段、估区间、多选。底座预训练 22 万亿 token，最后 3.5 万亿为中期训练，侧重 agent 轨迹与工具调用，并把上下文拉到 256K。架构叫 tri-hybrid：24 层里 13 层门控短卷积（卷积核 7，上一代为 3）、5 层 256 词滑窗注意力、6 层全局注意力；另加头级别的 sigmoid 门控、全局层只对每头高频一半做 RoPE、每个块输入输出都归一化。架构搜索是硬件在环的，从上一代的一部手机加一台笔记本 CPU 扩到 14 种设备与后端（三星 S26 Ultra、一加 15、树莓派 5、M4 Max、Ryzen AI、Arm 与 x86 云 CPU、高通 Hexagon NPU）。文本模型 4 位精度约占 1GB，每个模型都能在单卡上微调。厂商自报综合平均 49.37，高于 Qwen3.5-9B 的 47.24；WebArena-Verified 38.42 对 28.94；但在 SWE-bench Verified（43.40 对 51.20）、GPQA Diamond（63.37 对 80.40）与 128K 长上下文（65.56 对 87.11）落后，官方承认不打算用于 agentic coding 与多步复杂推理。许可证是重点：LFM Open License v1.0 以 Apache 2.0 为底，加了一条商业使用门槛——年营收低于 1000 万美元免费商用，达到或超过则不覆盖，需单独洽谈；官方通篇写 open-weight，不写 open source。

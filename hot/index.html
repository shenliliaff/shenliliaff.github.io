    他们把 322 个小蛋白送去实验室，35 个粘上了学术公益
    • 11-24 OpenAI 发预印本与博文：GPT-6 家族只靠推理加通用编程工具，不调用专用生物模型，就能设计蛋白质三维结构与氨基酸序列
    • 湿实验硬数字：322 个 minibinder 对 5 个靶点，35 个（10.9%）检出结合；OpenAI 自己承认 RFdiffusion 原论文命中率更高
    • 序列再设计：MDM2 85%（75/88）、VEGF-A 62%（26/42）、PD-1 14%（8/59）；抗体 CDR 重排 70%（128/182），上市抗体片段 66%（179/272）
    • 计算任务：motif scaffolding 通过率 43.7% 对 RFdiffusion 27.8%，CATH 折行 18.9% 对 Proteina 17.1%，对接 PoseBusters 93% 对 DiffDock-L 50%
    • 短板与留白：整链结构预测 TM-score 仅 0.38（ESMFold2 0.93），候选仍需 Boltz-2、ESMFold2 过滤，官方称尚不能零样本端到端，预印本未同行评审
    完整摘要

    2026 年 11 月 24 日，OpenAI 在官网发布预印本配套博文《GPT-6 Models Demonstrate Intrinsic Protein-Design Capabilities》，论文题为《GPT-6 as a Universal Foundation Model for Protein Biology: Beyond Specialized Models》。核心主张是 GPT-6 家族具备「内生的」蛋白质设计能力：只靠推理与通用编程工具，不调用 RFdiffusion、ProteinMPNN 这类专用生物模型，就能设计新的蛋白质三维形状和氨基酸序列，还能用自然语言指定结合位点、螺旋与片层的数量与排布。硬数字：与实验伙伴 Onava 做湿实验，322 个 minibinder 对 5 个靶点，35 个（10.9%）检出结合，分布为 PD-L1 5 个、IL-7Rα 3 个、TrkA 1 个、VEGF-A 8 个、IL-17A 18 个；OpenAI 自己注明 RFdiffusion 原论文命中率更高，但命中率高度取决于筛选严格程度与「结合」的定义。只给结构不给序列的再设计实验中，MDM2 88 个里 75 个结合（85%）、VEGF-A 42 个里 26 个（62%）、PD-1 59 个里 8 个（14%）；三组未公开结构的新序列 107 个里 14 个（13.1%）结合。抗体侧，6 个 VHH 的三段 CDR 重排 182 个测了 128 个结合（70%），5 个已上市治疗性抗体的 272 个片段里 179 个（66%）保持结合。计算任务上，motif scaffolding 在 MotifBench 30 个挑战上最新内部模型通过率 43.7%，RFdiffusion 27.8%；按 CATH 折行设计 200 个挑战通过率 18.9%，专用模型 Proteina 17.1%；分子对接 PoseBusters 上 GPT-6.2 命中 93%、内部模型 96%、DiffDock-L 50%。抗体-抗原 DockQ 均值从 GPT-5.6 的 0.05 升到 GPT-6 的 0.28、GPT-6.2 的 0.57、内部模型的 0.81。留白：全文最弱的一项是「只给序列预测整体结构」，TM-score 内部模型 0.38，专用模型 ESMFold2 为 0.93，OpenAI 自己写成「clear weakness」；整个设计流程仍靠 Boltz-2、OpenDDE、ESMFold2 过滤候选，官方明确「尚不能证明可零样本端到端生成 minibinder」；预印本未经同行评审，结合只是成药的第一步，特异性、稳定性、生物活性均未验证；生物安全仅提及按 Preparedness Framework 评估。

    智谱把 28 层跑了两遍，然后说这等于一个 2 万亿到 3 万亿参数的模型模型发布
    • 11-23 智谱发布 GLM-5.4：750B 基座不变，把第 27–54 层共 28 层权重共享跑两遍，官方称智能水平相当于 2 万亿—3 万亿参数模型
    • 唯一量化证据是同架构 30B 的等参对照：训练算力只多约 10%，AIME25 19.17→30.42、GPQA-Diamond 47.58→56.26，平均输出长度反降 2%–14.9%

    完整摘要

    2026 年 11 月 23 日，智谱（Z.ai）通过官方技术博客与官方公众号发布新一代旗舰模型 GLM-5.4，称其为第一代采用 Loop Transformer 架构的旗舰模型。做法是不加参数、加深度：把 GLM-5 基座第 27 至 54 层共 28 层权重共享，在一次前向里跑两遍，第二遍在第一遍的隐状态上继续推演。基座规模 750B（官方口径约 7500 亿参数），官方称其智能水平达到 2 万亿至 3 万亿参数级模型的效果，但没有公布 GLM-5.4 本身的任何跑分。能查到的量化数据全部来自一个同架构 30B 模型的等参对照——参数完全相同、训练算力只多约 10%：AIME25 从 19.17 升到 30.42、GPQA-Diamond 47.58→56.26、AA-LCR 40.33→47.67、MMLU-Pro 71.65→75.05、IFBench 50.20→53.47，同时平均输出长度反而降了 2%–14.9%，官方解释是一部分推理从 token 流搬进了循环带来的额外深度。为压住部署成本做了三处工程改动：每轮独立的逐 token 门控（第一轮保守写回、第二轮放开）、KV Cache 跨轮共享加滑窗独立、稀疏注意力索引直接复用第一轮结果；官方称在 1M 上下文下相对 GLM-5.3 的部署成本增幅「可控」，非高峰最高 200 token/s、高峰 70–80 token/s。可用性上，即日起向 GLM Coding Plan 全量用户开放，同步上线 ZCode、Trae、WorkBuddy、Qoder 等编码平台，Coding Plan V2/V3/团队版额度提升至 1.5 倍；API 需等安全评估完成，权重「计划以负责任的方式开源」但要先做完安全加固，两项均未给时间表。模型对比的胜平负来自 200 个真实场景的编程实战评测：对 GLM-5.3 是 51.1%/25.7%/23.1%，对 Kimi K3.1 Pro 是 41.8%/26.9%/31.3%，对 DeepSeek-V4.1-Flash-1017 是 36.6%/30.2%/33.2%。官方主动写出的短板是模型容易陷入过长的「马拉松式思考」循环，但称这种反复自省确实能让准确率超出其参数规模。同篇博客预告下一个模型「规模显著更大，很快见面」。留白：2T-3T 是自评、无第三方复现，AI Release Tracker 与 Artificial Analysis 当晚均未收录该模型，API 与权重都还没有确切日期。

维度取值含义

收录与核验规则

环节规则
发现聚合站（Hacker News / Techmeme / 机器之心 / 量子位）负责「今天有什么动静」
核实一律回溯官方站（openai.com / blog.google / anthropic.com / worldlabs.ai / spacex.com / hai.stanford.edu）确认参数与日期
入榜官方一手信源确认后方可入榜，并同步进「AI 动态追踪」
排除无官方出处的传闻、聚合站编造内容（历史案例：某 recap 文虚构「GPT-5 Turbo」「OCIE」）一律剔除
日期以官方公告的发布日为准，不接受「媒体转述日」冒充；纯媒体报道单独标注来源性质
时效每天更新必须包含当天（或前一天）的事件；若当天确实无大事，就少加或不加，绝不用两三天前的旧事件充数

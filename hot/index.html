    百度把 Token 摆上柜台：词元所 11-12 正式上线，验模型指纹、给供应商发信用分，同一款模型最多 12 家卖家同台比价行业动态
    • 11-12 百度世界 2026 开幕式正式推出「词元所」（cysuo.com），定位大模型 Token 交易与调用平台，百度百科标注上线日 2026-11-12
    • 两项能力：验真＝模型指纹比对 + 能力测试 + 性能可用性测试 + 定期抽检拨测 + 全链路监测；征信＝按稳定性、能力兑现度、合规、履约记录打分并公开
    • 台上数字为供应资源超 100 个、日均调用 5000 万次、日均 Token 超 7000 亿；官网首页却写 200B+ Token、6 千万+ 调用、70+ 模型资源，两套口径未对齐
    • 官网同一款模型多家供应：glm-5.3-flash 12 家、deepseek-v4.1-flash 6 家、kimi-k3 4 家，输入价 0.52 至 13.68 元每百万 token 不等；注册须手机号 + 实名认证 + 充值
    • 留白：官方只讲「验真」与「征信」，未提转售他厂模型是否获授权，也未公布抽检频次、评级算法与平台抽成
    完整摘要

    2026 年 11 月 12 日，百度世界 2026 在北京举办，李彦宏在开幕式上正式推出大模型 Token 交易平台「词元所」（官网 cysuo.com，百度百科词条标注上线时间 2026-11-12）。定位是把 Token 采购从「词元中转站」的灰色地带搬进有准入、有监测、有信用评价的平台：一端汇聚模型与供应商，另一端服务企业、开发者与个人，可在同一平台选型、比价、统一 API 接入。两项核心能力为「验真」与「征信」——验真靠模型指纹比对（防止供应商在后台替换模型）、能力测试、性能与可用性测试、上线后定期抽检拨测、全链路实时监测调用；征信按服务稳定性、能力兑现度、安全合规、商业履约记录给供应商打分，信用档案公开可查，信用下滑时主动提醒使用方。李彦宏给出的理由是词元中转站「并不对模型效果和服务稳定性负责……甚至连模型的真实性都无从考证」。两组数字对不上：台上说上线一个月入驻供应资源超 100 个、日均调用次数突破 5000 万、日均调用 Token 超 7000 亿；官网首页写的是「200B+ 日均 Token 调用、6 千万+ 日均调用次数、70+ 模型资源」，口径（供应资源与模型资源）与量级都不一致，百度未作解释。官网模型市场显示同一款模型对应多家供应商：glm-5.3-flash 12 家、deepseek-v4.1-flash 6 家、kimi-k3 4 家、ERNIE-5.1 仅 1 家，输入价格从 0.52 元到 13.68 元每百万 token。同一场大会还发了文心 5.5 Flash 预览版（2800 亿总参、每 token 激活 140 亿、100 万 token 上下文）、文心闪电深度思考与文心一镜微表情两款应用模型（上架千帆）。官方通篇只讲「验真」，未提第三方转售模型是否取得原厂授权，也未公布抽检频次、评级算法与平台抽成方式。

    欧盟今天把「关掉按钮」写进提案：成瘾设计用户可关，谎称「只剩 1 件」直接算违法，罚则最高全球年营业额 6%行业动态
    • 11-11 布鲁塞尔公布：可关的是官方列举的自动播放、与该服务上自身活动无关的通知，发布会另提无休止滚动；媒体标题里的「AI 陪伴」并不在 DFA 的可关清单上
    • 黑名单直接点名商家文案：只剩 1 件、还有 5 位顾客在关注、我们很难过看到你离开、我不喜欢好价按钮、预勾选加购，一律认定为任何情况下都不公平，不必再证明损害
    • 订阅与试用这几条最贴体感：须有一键取消、试用转付费前主动确认、续费前提醒，合同出问题时消费者有权找真人客服
    • 罚款最高全球年营业额 6%，但这条在同步提出的 CPC 条例修订里，且有门槛：影响至少三分之二成员国、至少三分之二欧盟人口、涉事公司非中小企业
    • 官方算账每年给欧盟消费者省最多 137 亿欧元；提案仍须欧洲议会与理事会审议，AI 陪伴的强制安全设计目前写在只管未成年人的 EU KIDS Act 里
    完整摘要

    2026 年 11 月 11 日，欧盟委员会在布鲁塞尔公布《数字公平法案》（Digital Fairness Act，DFA）提案，同时提出《消费者保护合作条例》（CPC 条例）修订提案与《消费者权利指令》简化修订，合称消费者一揽子计划；委员会称这是 20 多年来欧盟消费者保护规则最大的一次改革。DFA 的核心是把 2005 年《不公平商业行为指令》升格为在成员国直接适用的条例，并补上数字场景条款：消费者有权关闭鼓励过度或强迫性使用的成瘾性设计功能（官方问答举的例子是视频自动播放、与该服务上自身活动无直接关系的通知，发布会上另提「无休止滚动」）；重写「在任何情况下均属不公平」的黑名单，把谎称即将售罄（只剩 1 件、还有 5 位顾客在关注这件商品）、羞辱式挽留（我们很难过看到你离开、我不喜欢好价按钮）、预勾选框与自动加购列为违法，监管机构无需再逐案证明损害；虚拟应用内货币须标明真实货币价格，未成年人账户默认关闭虚拟货币，抽奖箱与付费获胜、付费推进对未成年人禁止；动态定价与虚拟排队须实时显示当前价格与最高可能价格，禁止把附加费藏到结账环节的 drip pricing；订阅须提供简单明确的取消入口，免费试用转付费前须取得主动确认、自动续费前须提醒，合同履行出问题消费者有权联系真人客服；针对未成年人的个性化广告禁令与敏感数据定向禁令从只管在线平台扩展到所有网站与 App，并禁止向未成年人及弱势消费者展示更高的个性化价格。委员会影响评估称这些规定预计每年为欧盟消费者省下最多 137 亿欧元。执法侧另有安排：同步提出的 CPC 条例修订拟授权委员会在影响至少三分之二成员国、覆盖至少三分之二欧盟人口的跨成员国大案中直接调查并罚款，上限为企业全球年营业额的 6%，门槛之一是涉事公司不属于中小企业；非欧盟企业须在欧盟指定法律代表。值得注意的是，AI 陪伴与聊天机器人并未出现在 DFA 的可关清单里——官方问答提到这两个词的位置是解释 DFA 与《欧盟儿童法案》（EU KIDS Act）的关系，后者才对社交媒体、视频分享平台、网络游戏、AI 陪伴与聊天机器人提出安全设计要求，保护对象是未成年人；DFA 里另一处与 AI 直接相关的条款，是消费者用 AI 代理代为购物时享有的明确权利。提案接下来须由欧洲议会与理事会审议，条款仍可能修改。

    完整摘要

    2026 年 11 月 11 日（美国时间，北京时间已是 12 日凌晨），Google DeepMind 在官方博客发布 Gemini Decisions API，由新模型 Gemini Decision 1（模型 ID gemini-decision-1）提供能力，已在 Google AI Studio 的 Gemini API 上线，另有 OpenRouter、LangChain、Vercel、LiteLLM、Pydantic AI、Pipecat、LiveKit、OpenCode 等集成陆续铺开，Google Cloud 侧标注为「即将支持」。它不逐 token 生成文本，而是在一次前向计算里对你给的封闭问题打分，返回概率与 0—1 的置信度：单次请求可携带最多 256K token 的混合输入（文本、图像、音频、视频、PDF），并挂最多 1000 道问题；题型三种——noul（是/否，返回概率）、choice（2 至 255 个选项，返回胜出项与每个候选的归一化概率）、score（按有序评分标准返回连续加权分与各档概率）。官方给的端到端延迟是 150—250 毫秒，16K 上下文以内模型计算中位数 50—100 毫秒，且从 1 道题到 100 道题延迟几乎不变。定价每百万输入 token 0.10 美元、输出 token 不计费（按输入计一次，挂多少道题都只算一次），AI Studio 另有免费试用额度；谷歌称在共享基准集上比走 Interactions API 的 Gemini 3.5 Flash-Lite 便宜近 5 倍。官方点明的四类用途是工具选择、策略检查、模型路由与上下文分级，并披露四个内部落地：Gemini Notebook 用它做实时路由，把日常查询延迟降低最多 40%；Stitch 的快速画布用它秒出可点原型；Google Labs 的 CC 用它从 200 多个表情里挑一个；Google 搜索用它给 MCP 工具做对抗性行为的安全闸门。

环节规则
发现聚合站（Hacker News / Techmeme / 机器之心 / 量子位）负责「今天有什么动静」
核实一律回溯官方站（openai.com / blog.google / anthropic.com / worldlabs.ai / spacex.com / hai.stanford.edu）确认参数与日期
入榜官方一手信源确认后方可入榜，并同步进「AI 动态追踪」
排除无官方出处的传闻、聚合站编造内容（历史案例：某 recap 文虚构「GPT-5 Turbo」「OCIE」）一律剔除
日期以官方公告的发布日为准，不接受「媒体转述日」冒充；纯媒体报道单独标注来源性质
时效每天更新必须包含当天（或前一天）的事件；若当天确实无大事，就少加或不加，绝不用两三天前的旧事件充数
更新顺序每天先更新本榜单，再去写博客文章——榜单是「今天发生了什么」的索引，不能等到文章写完才刷
复核每次更新逐条回访官方链接，确认页面存在、日期与标题匹配（曾发现某条日期错标 4 个月，已修正）

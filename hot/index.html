    • 11-02 美团发 LongCat-2.5：总参 1.6 万亿、每 token 激活约 480 亿，全程国产算力训练，官方称是国产算力上最大规模的训练任务
    • 为绕开国产卡单卡显存小，把参数与数据的主通信压进超节点，长上下文 SFT 单卡吞吐较 DDP 基线 +86%；W4A4 推理相对 W8A8 吞吐各涨约四成
    • 评测只说「介于 Claude-Opus-4.8 与 Opus-5 之间、部分超过」，没分数也没测试配置，是全篇最含糊的一段

    • 8-28 财报会上王兴说「我们不会成为 Token 工厂」，而同期行业正把 Token 摆上双十一货架打折卖——模型不谈 token，谈毛利
    完整摘要

    11 月 2 日，美团发布 LongCat-2.5，定位「面向长程智能体任务的原生多模态模型」，总参数 1.6 万亿、每个 token 激活约 480 亿，训练全程在国产算力上完成，美团称这是目前国产算力上完成的最大规模训练任务（今年 6 月的 LongCat-2.0 首次在国产卡上跑通万亿参数的全流程训练与推理）。技术上三处要点：视觉信号被表示成多层级离散 token 与文本统一处理，支持交互网页与 3D 展示页面；中训练阶段序列最长达 1M token、累计数万亿 token，针对国产卡单卡显存小的短板把参数与数据的主要通信压进超节点内高速互联，长上下文监督微调的单卡吞吐较 DDP 基线提升 86%（折算约 1.86 张卡的工作量）；推理用 W4A4，专家权重与激活都压到 4 比特，相对 W8A8 INT8 基线输入处理与逐 token 生成吞吐各提升约四成，首次出字快约 16%、后续每 token 快约 20%。评测口径含糊：官方只说多项主流基准介于 Claude-Opus-4.8 与 Claude-Opus-5 之间、部分超过后者，没给分数与测试配置。真正落地的是商业分析——技术博客里模型自主搭出渠道利润表，识别出支付 GMV 涨 23.2% 而渠道利润掉 1.7%，进而结合清货经济价值、复购与库存风险给差异化资源配置建议；配套的 AI 经营工作台「妙手」已服务古茗、徐升记、益禾堂等连锁品牌，在商家授权范围内调工具、调系统执行任务。用户在 longcat.ai 体验，开发者走同步上线的 API。

    腾讯混元 11 月 2 日发 Hyra 2.0：不答题了，改让 agent 造科研工具，顺手交出一只先慢 11% 后来快 28.6% 的手学术公益
    • 11-02 混元发 Hyra 2.0，路线从「刷题解题」转向「造工具」；理由是答案用一次、工具能被下游反复用，形成「智能复利」
    • Hyra 1.0 三个月前靠 Hy3 解决加法组合学悬置五十余年的和集差集最优指数；官方博客自列对照：同期 OpenAI 公布了 Astra 在 10 个开放问题的新结果与 722 篇数学手稿
    • 三层 Overall/Mission/Worker + 持久化队列 + 人工审批，Worker 交差必须附代码、日志与原始轨迹，独立结论另起 Review Worker 先看原始问题
    • 交出的成果横跨五个方向：HyInv 快 ProteinMPNN 57 倍、HyPLM-Flash 6.5 亿参数、HyFF 模拟 6 万原子膜体系、HyProver 核验丘成桐圆周作用猜想、HyQEC 量子码编码效率高约 48%
    • 最能说明问题的细节是「旋梯手」：第一版比最优设计慢 11%，训练后快 28.6%；它还参与下一代混元模型研发，工具与模型互为对方的工具
    完整摘要

    11 月 2 日，腾讯混元发布自动化科研框架 Hyra 2.0，把重心从「让 AI 直接解题」转到「让通用 agent 研发并升级可复用的科学模型、研究工作流与软件工具」。起因是 Hyra 1.0（约三个月前发布的极简 agent 循环）已经证明刷题路线可行——发布一周后驱动开源模型 Hy3 解决加法组合学中悬置五十多年的「和集与差集最优指数」，为国产开源模型首次全自动解决数学开放问题——但混元认为解出一道题只得到一个答案、不提升下一次研究的能力，而工具升级的收益会被所有下游任务反复复用。工程上把研究工作拆成 Overall（对齐人类目标、管优先级与资源）、Mission（长期负责单一问题、定路线、对结论负责）、Worker（独立读代码、做实验、分析失败，可质疑 Mission）三层，接进真实环境（企业微信对齐需求、计算平台提交实验、代码仓库改代码），大算力与共享知识同步操作需人工审批，任务进持久化队列，等待训练或审批时其他任务照跑。硬规矩是证据：Worker 交差须附代码版本、实验结果与日志或原始轨迹，需要独立验证时另起 Review Worker 先接触原始问题以避开执行者结论的影响；经验分项目状态、agent 分层记忆、共享知识库 Books 三套存，Books 里分「观察 / 已验证 / 约定」三级，约定须人类确认。成果：HyInv 196 万参数做蛋白质逆折叠，比 ProteinMPNN 快 57 倍，单张 H20 上 128 条约 400 残基序列约 50 毫秒；HyPLM-Flash 6.5 亿参数、7260 亿 token；HyFF 五个规模 230 万至 12 亿参数、覆盖 83 种元素，模拟近 6 万原子水通道蛋白 100 纳秒、4.6 万原子酶体系看到完整断键成键；HyProver 与数学家核验丘成桐圆周作用猜想、五维 Petty 等距点猜想；HyQEC 构造量子码 [488,123,22]，kd²/n 达 122.0，比 qLDPC Challenge 原榜首高约 48%，并把原榜首码距上界从 95 收紧到 86；香山 RISC-V 的 SPEC CPU2006 每 GHz 性能 +5.79%、面积仅 +0.3%；灵巧手自主设计出五指绕掌心、由短到长的「旋梯手」，最初比最优设计慢约 11%，同预算控制算法训练后仿真转速 3.28 rad/s 对基线 2.55、快 28.6%。它已参与混元下一代模型的预训练、后训练与推理系统优化。
